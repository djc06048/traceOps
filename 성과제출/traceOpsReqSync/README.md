# traceOpsReqSync

TraceOps와 ReqSync를 하나로 묶은 성과 제출 자료 폴더입니다. 아직 작성 전이며, `prowin/` 과 같은 구조로 만듭니다.

```
traceOpsReqSync/
├─ build_traceopsreqsync.py   장 구성과 문구 (prowin/build_prowin.py 를 참고)
├─ 성과제출_TraceOps_ReqSync.html
└─ shots/                      화면 캡처
```

- 공통 디자인 기준은 `../작성가이드.md`, 공통 부품은 `../tools/deck_lib.py` 입니다.
- 내용 출처는 `../제안서_추진현황_요약.md` 의 1장(ReqSync)과 3장(TraceOps)입니다.
