개요
성과 요약AI 활용
AI 기반 요구사항 개정 검토(ReqSync)와 연계관리를 포함한 TraceOps로 요구사항부터 연계 검증까지 추적 체계를 구현했습니다.
로컬 LLM이 회의 결정사항을 추출하고, 연계관리는 프로세스 단위로 누락을 확인하고 검증합니다.

AI 추출 결과를 PL이 원문과 비교해 확정하는 검토 화면을 구현

TraceOps · ReqSync 소개AI 활용

회의 결정사항은 근거와 함께 요구사항에 반영되고, 하위 단계는 같은 요구사항 기준을 사용합니다.

개요

프로젝트는 착수, 기술협상, 분석, 설계, 개발·단위테스트, 통합테스트 순서로 진행되며 단계마다 산출물이 확정됩니다.

보완 근거가 회의록에만 남고 반영은 수작업

메서드 하나가 개발 대상에서 빠지면 프로세스 전체가 동작하지 않음

03
정합성
수작업 관리와 매핑 누락

요구사항, 분석, 설계, 개발, 테스트를 엑셀과 PMS로 수작업 관리해 정합성 보장이 어려움

개발 목록을 실수로 삭제하면 요구사항이 어디에도 매핑되지 않아 누락될 수 있음

해결 방향

연계관리 개요
연계관리는 기간계의 메인 프로세스뿐 아니라 채널과 AI Agent 등 기간계 바깥의 연계까지 프로세스로 관리하는 기능입니다.
프로세스 안의 메서드가 하나만 빠져도 동작하지 않으므로, 누락을 막고 연계 테스트케이스로 검증하기 위해 필요합니다.

필요한 이유 1

메서드 누락 방지

메인 프로세스의 메서드는 담당 개발자가 서로 달라 한 사람이 전체를 파악하기 어렵고, 하나만 빠져도 프로세스가 동작하지 않음

필요한 이유 2

연계 테스트케이스

프로세스 기준으로 단위테스트를 묶어 처음부터 끝까지(E2E) 수행하고, 어떤 프로세스를 테스트해야 하는지 파악

필요한 이유 3

기간계 외 연계 관리

채널이 기간계의 어떤 메서드를 호출하는지, AI 기능이 어떤 기간계 호출에 의존하는지 확인

운영 방식
PL과 메인 설계자가 프로세스를 등록·설계하고, 하위 메서드는 개발 항목이 되어 개발자별로 배분됩니다.
개발 항목 기준의 통합테스트와 달리, 프로세스 기준으로 단위테스트를 묶은 연계 테스트케이스를 구성해 테스트 대상과 결과를 확인합니다.
