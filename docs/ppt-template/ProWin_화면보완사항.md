# ProWin 화면 보완사항 (개발자 전달용)

> 기준: `main` 브랜치 `ProWin/backend` (Spring Boot 3.3.5 · Java 17 · SQLite) 를 로컬에서 기동하여 화면을 촬영하고 업로드·합본을 시험하며 확인한 내용.
> 성과 보고 자료에는 넣지 않는다. 보고 자료에는 `향후 계획`(고도화 과제)으로만 표현한다.

## B. PPT 미리보기 (제안서 검토 화면에서 실제 PPT가 보이도록)

**결론: 가능하다.** 현재 `PptxRenderer` 가 Apache POI(`XSLFSlide.draw`)로 슬라이드를 PNG로 그리고 있어, 도형·색·텍스트·표는 실제 PPT와 거의 같게 나온다. 한화시스템 보고 템플릿(29장)을 실제로 올려 시험한 결과 아래와 같았다.

| 항목 | 시험 결과 |
|------|----------|
| 도형, 색상, 표, 머리 막대, 텍스트 배치 | 원본과 거의 동일하게 렌더링 |
| 글머리 기호(Wingdings 등 기호 글꼴) | `♣` 로 깨져서 표시 |
| 나눔바른고딕 등 지정 글꼴 | 서버에 글꼴이 없으면 대체 글꼴로 표시되어 줄바꿈이 달라질 수 있음 |
| 이미지 | 표시됨. EMF/WMF 같은 벡터 이미지, SmartArt, 차트는 누락·왜곡 가능성 |
| 해상도 | `PREVIEW_WIDTH` 고정 썸네일. 화면에서는 약 250px 폭으로 줄어 글자를 읽을 수 없음 |

보완 요청 (효과가 큰 순서)

1. **슬라이드 뷰어**: 썸네일 클릭 시 모달 또는 우측 패널에 큰 이미지(1200~1600px)로 표시, 이전/다음 이동, 슬라이드 번호 표시.
2. **서버 글꼴 설치**: 나눔바른고딕(및 한화 사용 글꼴)을 서버에 설치하고, Wingdings 등 기호 글꼴은 글머리 기호 대체 매핑 적용.
3. **미리보기 캐시**: 현재는 요청마다 PPTX를 열어 다시 그린다. 커밋 시점에 PNG를 파일로 저장해 두고 재사용.
4. **고충실도 옵션(필요 시)**: 차트·SmartArt·EMF 때문에 품질이 부족하면, 서버에 LibreOffice(headless)를 두고 `PPTX → PDF → PNG` 로 변환하는 방식을 비교 검토. 정확도는 높아지지만 서버 설치와 변환 시간이 늘어난다.
5. **슬라이드 이미지 방식 합본 미리보기**: 합본 스냅샷도 같은 뷰어로 열 수 있게 연결.
